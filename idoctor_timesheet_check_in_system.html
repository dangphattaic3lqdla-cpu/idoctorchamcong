Xuất Web Chạy Độc Lập (Không cần Gmail / Gemini)

Lưu dữ liệu trực tiếp vào Google Sheets của bạn & mở được trên mọi điện thoại

1 Tạo Google Sheets & Dán mã kết nối (Apps Script)
  1. Mở sheets.new để tạo 1 file Google Sheets trống mới cho công ty.
  2. Trên thanh menu chọn Tiện ích mở rộng (Extensions) → Apps Script.
  3. Xóa toàn bộ chữ mặc định trong khung code, bấm nút Sao chép mã Apps Script ở trên rồi dán vào và bấm Lưu (Ctrl+S).
2 Xuất bản đường dẫn kết nối (Web App URL)
  1. Ở góc trên phải Apps Script, bấm Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment).
  2. Bấm biểu tượng bánh răng chọn Ứng dụng web (Web app).
  3. Mục Thực thi dưới dạng (Execute as) chọn Tôi (Me); mục Người có quyền truy cập (Who has access) chọn Bất kỳ ai (Anyone).
  4. Bấm Triển khai, cấp quyền cho tài khoản Google của bạn, rồi copy đường dẫn URL ứng dụng web (dạng https://script.google.com/macros/s/.../exec).
3 Dán URL vào đây để tải file index.html độc lập

Bước cuối đưa lên mạng (miễn phí): Vào app.netlify.com/drop (hoặc GitHub Pages / Google Sites), kéo thả file index.html vừa tải về là có ngay link web công khai. Nhân viên mở trên bất kỳ điện thoại nào cũng chấm công được ngay mà không cần đăng nhập Gmail!
